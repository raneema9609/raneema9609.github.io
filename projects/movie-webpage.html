Zootopia 5 Project

Context

The project I chose was inspired by the movie Zootopia. I collaborated with a partner to create an imaginary movie website, utilizing our understanding of basic HTML and CSS for the SEP Movie Project.

Content

Me and my partner had made an addtional movie inspired by the already produced Zooptopia 1 and 2. We created a new somber ending to the movie of whic the main character, Judy Hopps gets killed by her former boss, (chief Bogo) while trying to save her partner (Nick Wilde). Using HTML, we made headings, paragraphs, divs,inputs, and more. With CSS, we were able to change and add things like colors of background and text, borders, margins, padding, and fonts.

Reflection

Challenges: While creating our project, we repeatedly ran into issues adding divs, spans, and classes throughout the code. This provided a learning experience and increased our knowledge of writing code with fewer mistakes. Another problem we encountered was that most of our work on the project took place at home, causing less communication between us, which made it harder to work at the same pace.

Takeaways:

  • Communication
  • Ask Questions
  • Meet all the needed requirements to acheieve a 100
  • Plan Project efficiently
  • Stay on task during class time

Next Steps:

My next steps for this project is that I want to be able to create another sequal since we didn't have enough time previously to do so. Another thing I want to achieve is to finially be able to create something in the near future based on this story.
